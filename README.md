# Class of GH-300

## Agenda

### Course Overview
This class covers advanced GitHub and development practices, including version control, collaboration, and CI/CD workflows.

### Learning Objectives
- Understand GitHub workflows and best practices
- Master Git commands and branching strategies
- Implement continuous integration and deployment
- Collaborate effectively on code projects

### Topics
1. GitHub Basics and Repository Management
2. Branching Strategies and Workflows
3. Pull Requests and Code Review
4. GitHub Actions and CI/CD
5. Collaboration and Team Management
6. Advanced Git Techniques

### Schedule
- Week 1-2: GitHub Basics
- Week 3-4: Branching and Workflows
- Week 5-6: Pull Requests and Code Review
- Week 7-8: GitHub Actions and CI/CD
- Week 9-10: Team Collaboration
- Week 11-12: Advanced Techniques and Project

### Assessment
- Participation: 20%
- Assignments: 40%
- Final Project: 40%
